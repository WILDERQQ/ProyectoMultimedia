2. Objetivos del Proyecto

Este proyecto engloba la investigación e implementación de tecnologías interactivas multimedia aplicadas en entornos web y simulaciones 3D. A nivel grupal, aborda la digitalización y modelado de procesos universitarios reales (BPM/BPMN) y el desarrollo de simuladores gráficos en 3D interactivos con motores como Three.js y Unity WebGL. A nivel individual, explora algoritmos fundamentales de tratamiento de imágenes (filtros convolucionales en Canvas) y reproducción síncrona multimedia.

3. Tecnologías Empleadas

HTML5 Canvas API Vanilla Javascript Three.js (WebGL) Unity 3D & WebGL PHP 8 JSON Flat DB BPMN 2.0 (Bizagi) Node.js

4. Estructura Grupal

A. Trámites UMSA (BPM): Modelado completo de flujos de solicitud de Certificados y Títulos Académicos, con un back-end PHP integrado que gestiona solicitudes en tiempo real y almacena la información directamente en archivos planos JSON.

B1. Animación Sincronizada (Unity): Implementación de avatares animados sincronizados con pistas de audio en un entorno interactivo compilado en WebGL de alto rendimiento.

B2. Visor 3D (Fotogrametría): Renderizado web 3D optimizado con control de órbita y sombreado ACES Filmic que carga directamente modelos fotogramétricos en formato GLB comprimido.

5. Laboratorios Individuales

Cada miembro cuenta con una estructura dedicada en /individuales/[estudiante] donde se alojan tres módulos independientes: clasificación de texturas mediante lectura de píxeles, filtros gaussianos 3x3 de suavizado para reducción de ruido gráfico, y animaciones síncronas del clásico infantil "La Vaca Lola" mediante audio interactivo y canvas dinámicos.
